# 课本里的高考

可独立部署的高中语文学习网站。首页直接展示统编必修上册《劝学》教材选文完整四段，二十余处词句标注可查看释义、考点、原文作用，以及文言阅读、名句默写、作文应用的迁移提示。阅读无须登录，练习完全自愿。

技术栈：Next.js 16 App Router、TypeScript、React、PostgreSQL、Prisma 6、OpenAI Responses API。界面采用黑白紫的阅读风格，以橙色提示易错点和重点，支持手机、键盘操作和中文读屏标签。

课文下方新增逐段注释索引、旧课文同字对照、陌生句翻译和全文白话对照。注释按所选四段逐词整理，并可回到原文位置；旧课文比较标明篇名与同字异义；全文译文按段与原文并列，按需展开。注释和译文均由本站重新撰写，**不是出版社教材原注逐字转录，也未取得出版社对版次和文字的校核确认**。若要公开展示教材原注全文，需先核对具体版次与转载授权。

陌生句练习提供本站自拟的预设短句，学生可先写译文，再看参考译文与逐点自查，不登录也能体验，且不计入掌握度。配置服务器端 OpenAI 密钥后，登录学生还可按目标词请求 AI 即时自拟短句；每人每 15 分钟最多 3 次。即时生成的句子和译文明确标记“未经教师审阅”，服务不可用或校验失败时不会冒充已审定的练习。

## 本机隐私模式

不需要公网、GitHub 或云数据库时，运行 `node scripts/setup-private-local.mjs`。它会生成只保存在 `.env.local` 的随机本机密钥，把现有 `.demo-data/store.json` 原子迁移为 AES-256-GCM 加密文件，并删除迁移成功后的明文文件。密码仍使用带随机盐的 `scrypt` 单向哈希，不保存可解密密码；项目不采集手机号。本机隐私模式只接受 `localhost` 或 `127.0.0.1` 请求，并禁止连接远程 PostgreSQL。

`.env.local`、加密学习数据和备份均已被 Git 忽略。丢失 `LOCAL_DATA_KEY` 将无法恢复加密数据，因此应把密钥离线保存在用户自己的安全位置，不能提交到代码仓库。

“这一句，读深一点”为全部 21 条标注提供字词拆解、完整句意、句式关系、论证链，以及阅读自拟例句、情境默写和原创作文片段。每处另有一条精读追问：学生先判断，再展开原文依据、推论与易误读处；迁移页写明适用边界。正文重点采用橙色底，答案与考点采用紫色强调，均带文字标签。考点页先显示关联原题，真题参考答案默认收起，学生可先写判断，再按题干提示、原文依据、自查要点、参考表达逐层查看；详情还给出原文证据、示范表达、本站自查维度和按题型选用的阅读支架。自拟例句和示范不充作真题或官方评分标准。

复习入口保留首页原文：可定位并高亮原文段落的四段骨架、橙色底标出的本站教学重点、四张速览卡和可展开的七类题型查漏。四张卡对应教材选文的四段，不表示全文只有四个知识点；末段的积累、坚持、专一可分别回到原句。情境默写可以先回忆再核对；真题档案的答案与依据按需分层展开。它参考了用户提供的[文言文阅读通关手册](https://fcfabff851e1429caa0129c2b360e181.app.workbuddy.host/)和笔记精华，再按《劝学》逐句重写。手册中的“固定 22 分”“先看第 12/14 题”“约 75% 正确率”不作为通用规则；具体题号、分值和作答顺序以当年原卷为准。学生答完原创短题后，未得满分的评分点自动归入字、词、句、篇四类复盘线索，可回到对应原句；演示评分的线索仍待人工复核。

真题详情新增一题一目标的自愿理解检查：看完分步解析后，选择一条判断理由，立即得到针对该选项的错因说明和下一步。2022“劣马”与 2026“骏马”可以互作变式；作文题通过强弱句对照、三项自查标准和一题判断，练习把课文原句与题目之间的推理说清。2023 文言概括题所依赖的两则材料尚未完整展示，暂不提供理解检测。自测为本站原创，选项误解尚未由真实学生答卷验证；作答不计分、不储存、不进入掌握度。学习足迹将重复点击合并为最近打开的不同考点，给出可回原文核对的简短复盘入口。阅读支架改为按需展开，避免把教师备课提纲当作学生必读任务。

## 现在就运行

需要 Node.js 22+ 与 pnpm。进入本目录：

```bash
corepack enable
pnpm install
pnpm db:generate
pnpm dev
```

打开 http://127.0.0.1:3000。**无需任何密钥即可体验**：未配置数据库时，开发环境自动采用 `.demo-data/store.json`；未配置 OpenAI 密钥时使用关键词规则评分。页面明确显示演示状态。无需创建默认账号；自行注册昵称、邮箱和至少 10 字符的密码。

Windows 上已有依赖时，可右键运行 `start-demo.ps1`。受限环境中 `next dev` 的子进程若不能启动，可运行 `node scripts/preview.cjs`；它仍启动真实 Next.js 服务。停止服务按 Ctrl+C。

建议体验：点“君子生非异也，善假于物也”→查看知识迁移→加入复习本→选择原创文言翻译短题→写自己的理解→查看逐点评分→在学习足迹查看历史。登录后注册前已输入的答案会保留；刷新与退出重新登录后仍能读取记录。

## 接入正式数据库

复制 `.env.example` 为 `.env`。填写：

```dotenv
DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/keben?schema=public
DATA_ENCRYPTION_KEY=至少32字符的独立随机密钥
DEMO_MODE=false
APP_ORIGIN=http://127.0.0.1:3000
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4.1-mini
```

然后执行：

```bash
pnpm db:migrate
pnpm db:seed
pnpm dev
```

迁移保存在 `prisma/migrations/`，其中第二次迁移为真题档案加入知识点、本站学习解析和易错提醒；种子可重复执行，不覆盖人工导入或授权状态。数据库包括学生、会话、卷别、题目档案、答案及原始评分、教师复核、阅读收藏/复习事件、掌握度、审计和限流记录。更换 `DATABASE_URL` 后重启进程。数据库连接失败返回服务错误，**不会静默退回本地文件**。

正式环境没有 `DATABASE_URL` 时将拒绝数据请求；只有显式 `DEMO_MODE=true` 才允许生产演示。文件演示只能单进程、单机运行，不适用于 Serverless、多副本或真实班级；正式版必须使用 PostgreSQL。正式数据库不会自动搬入演示账号。


云端 PostgreSQL 模式对邮箱、昵称、学生答案、评分反馈和复核说明使用 AES-256-GCM 应用层加密；密码始终只保存带随机盐的单向哈希，项目不采集手机号。`DATA_ENCRYPTION_KEY` 只放在服务器私密环境变量，不写入 GitHub；丢失密钥后现有记录无法解密。题号、来源和考点等公开教学资料不加密。

2015—2026 十二个考试年度的卷别目录已建立，题目管理支持真实年份、卷别、课标变体、题号、来源 URL、对应知识点、本站学习解析、易错提醒、课内标注，以及授权与核验两轴状态。2015、2017—2018 目前仅为目录，没有题目档案。

| 年份 | 当前管理范围 |
| --- | --- |
| 2015—2016 | 新课标Ⅰ / Ⅱ卷 |
| 2017—2019 | 全国Ⅰ / Ⅱ卷 |
| 2020 | 全国Ⅰ / Ⅱ卷与新高考Ⅰ / Ⅱ卷分别记录 |
| 2021—2022 | 新高考Ⅰ / Ⅱ卷；2022 旧课标默写变体独立建档 |

| 2025—2026 | 全国一 / 二卷 |

**这不是已收齐十二年完整试题的数据库。** 当前仅有 7 条可追溯来源档案：2016 新课标Ⅰ卷 10(1)、2019 全国Ⅰ卷 13、2020 全国Ⅱ卷 16(1)、2022 新高考Ⅰ卷旧课标版 17(1)、2023 新课标Ⅰ卷 14、2024 新课标Ⅰ卷 23、2026 全国Ⅱ卷 17(1)。七条原题文字在站内可读，来源页码逐条标注；全部授权仍为 UNKNOWN、正式核验仍为 PENDING。缺失年份如实显示零条。

2016、2020、2022、2026 的《劝学》原题在案例卡中标明来源与关联；答案需进入详情后分步查看，避免先被参考答案带走。2022“劣马”和2026“骏马”训练题干限定词与原文半句的精确对应。网页把填空横线统一排版，保留原题语义；用户提供的汇编 PDF 在2016、2020 重排了题号，因此档案题号还需与正式原卷核验。

逐条研究记录、二级来源限制与课标版本说明保存在 `prisma/source-research.json`。与《劝学》的“教学迁移关联”并不等于题目直接引用它，也不等于统计出的“高频考点”。网站没有伪造题目、考试频率或官方评分标准。

七条固定案例另配本站编写的学习讲解：客观题分层显示题干线索、逐点原文依据、自查要点和参考答案；详情给出完整原文证据、示范表达和自查维度。2024 作文题显示一种立意、一段本站原创表达、可替代立意和本站参考评价维度；分类图、对比图或过程图按具体题目选用，不套统一模板。作文指导引用[教育部教育考试院公开命题解读](https://fx.xwapp.moe.gov.cn/article/202406/6662af88813bc8035af97f4e.html)、[广州五中刘继斌教师公开点评](https://finance.sina.com.cn/tech/roll/2024-06-08/doc-inaxxupq3818651.shtml)、[深圳陈冬平教师公开点评](https://www.sznews.com/news/content/mb/2024-06/07/content_31003329.htm)及[羊城晚报广州师生作品与点评](https://ep.ycwb.com/epaper/ycwb/html/2024-06/17/content_8_651660.htm)作为审题参考；这些公开材料**不代表上述教师审核、认可或授权本站示范段落**。2019、2023 的站内参考答案取自原文理解并参考二级公开解析，尚未取得官方答案核验。

目前示范段落状态是“本站编写 · 教师审阅待完成”。若要标记为“教师审阅”，应保存教师姓名、学校/任教身份可核验依据、审阅日期、审阅版本、具体修改意见及授权记录，并由独立人员复核后更新状态。重点高中教师的名义不能仅凭一篇公开点评推断为对本站范文的背书。

档案中的知识点、学习解析和易错提醒属于本站教学内容；原题正文、参考答案属于另一个字段。新增的“考点复现”只统计有核验人、核验时间和证据的档案，并报告样本中的题数与不同年份数。题库未收齐时不推断十二年的真实出题率；当前零条已核验，因此明确显示样本不足。课文橙色底标记是人工选出的教学重点，不代表真题频次。管理员新增的课内标注会出现在原句考点面板；关联状态照常显示。

来源链接可公开访问不代表取得转载许可。七条固定案例以**资料阅读模式**在学生接口展示，标记“转载授权未确认”和来源页码，不冒称官方授权或核验；其中六条来自用户提供的试卷 PDF，2024 作文来自公开转引 PDF。其他管理员导入的题干只有在 `authorization=APPROVED` 且有授权凭证、`verification=VERIFIED` 且有核验证据/核验人/时间时才会展示。若固定案例被标记 DENIED 或 REJECTED，也立即撤下。所有变更保留审计；编辑档案重置两种状态。首版练习是**本站原创体验题、教学参考量规**，与真题分开。正式公开部署前，应由运营方确认转载许可。

古代《荀子》原文为公共领域文本；本项目自行编写现代注释，不复制出版社现代注释。展示的是教材所选四段，而非《荀子·劝学》整篇。标点和通假字应对照所用教材的具体版次进一步复校；尚无出版社对本项目的校核确认。

## AI 评分与人工复核

设置服务器端 `OPENAI_API_KEY` 即开启真实请求；密钥不会进入浏览器。`OPENAI_MODEL` 可更换为账号可用且支持 Structured Outputs 的模型。API 依据[官方 Structured Outputs 文档](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)使用 Responses API + Zod schema，`store:false`，仅发送题目、参考表达、量规和学生答案，不发送账号资料。

每点显示给分、最高分、答案中的原句证据、简短解释和自评把握度。服务器再次校验评分点完整且唯一、分数为范围内整数、有分必须有原答逐字证据。总分由服务器求和。输入作为数据处理，提示中的学生指令不能变更量规。模型拒答、不完整、超时或结果校验失败时，明确切换为规则演示，并提示复核。

模型置信度是自评，**未经校准，不是正确概率**；也不展示模型内部思维。低于 0.8、作文应用、全部演示评分进入复核队列；学生还可主动申请。人工反馈不是正式高考阅卷结果。

注册教师账号后，由有服务器权限的运营者执行：

```bash
pnpm account:role teacher@example.com REVIEWER
pnpm account:role admin@example.com ADMIN
```

教师登录后可领取匿名答案→逐点确认或改分→填写依据→提交。其他教师不能覆盖已领取答案；只有完成复核的人可提交。原始评分不覆盖，人工结果独立保存。完成后学生历史显示人工结果，并可展开原始辅助评分。

知识掌握度汇总已人工复核的评分点或无需复核的 AI 评分；未复核演示反馈不计入。它是已获得评分证据的比例，不是能力诊断或稳定的考试分数预测。阅读/收藏也不会直接伪装成已掌握。

## 导入真实题目

管理员的“题库管理”页面支持严格 JSON 导入原题元数据，并有独立的知识点、学习解析、易错提醒表单；随后分别进行原卷核验、授权确认、撤下题干和查看审计。学生不能获得管理员角色或调用管理接口。可以先保留 `body:null`，完成获取原卷与授权后再输入正文。示例结构（字段值为结构说明，不应直接作为真题导入）：

```json
{
  "id": "你的档案ID",
  "paperId": "2020-LEGACY-2",
  "number": "16(1)",
  "category": "名句默写",
  "title": "准确的题目档案标题",
  "sourceUrl": "https://真实原卷来源.example/scan.pdf",
  "sourceTitle": "来源名称与类型",
  "body": null,
  "reference": null,
  "annotationIds": ["rou", "bao"],
  "knowledgePoints": ["情境默写", "通假字与字形"],
  "learningAnalysis": "本站原创解析，说明如何从设问定位原文",
  "commonMistake": "本站原创易错提醒"
}
```

`paperId` 必须来自 `/api/exams` 目录；`category` 为文言阅读/名句默写/作文应用；`annotationIds` 来自 `lib/content.ts`。年份、卷名、变体由关联 Paper 提供，避免出现伪造的“2021 全国Ⅰ卷”。不能在导入 JSON 夹带授权或核验字段。除七条固定资料摘录外，学生接口在未满足两项条件时不会返回管理员导入的题干；学习解析独立显示并标明是否仍待原卷核验。评分闭环目前覆盖三道原创短题；导入真题正文后可以查看和关联课文，**不会自动生成或冒称官方评分量规**。扩展真题作答前必须另行编写经教师审核的评分点。

## 权限与运行约束

密码使用随机盐 scrypt；随机会话令牌只在 HttpOnly/SameSite Cookie 中保存，服务器只存令牌 SHA-256，7 天过期。正式 HTTPS 使用 Secure Cookie。学生全部数据读写以当前服务端会话身份过滤；教师只读取复核队列匿名答案；授权、导入和审计仅管理员可用。写请求校验 Origin 与 JSON 格式，限制长度和接口频率。权限从服务端查账号，不相信客户端提交的角色。

这是面向小班试点的纵向闭环。仓储目前集中加载数据，并用 PostgreSQL advisory transaction lock 串行化变更，保证演示与正式模式权限逻辑一致。大规模上线需改成逐用户/分页查询，减少全表读和全局锁，加入可恢复的复核领取超时、账号找回/邮箱验证、模型校准评估、监控与备份恢复演练。首版没有邮件发送、密码找回或全校级容量承诺。

反向代理后务必设置 `APP_ORIGIN` 为实际浏览器访问的完整 origin（不带末尾 `/`）。只有代理可信且覆盖 X-Forwarded-For 才启用 `TRUST_PROXY=true`。端口不直接暴露到公网，使用 HTTPS 代理。

本次实测状态及环境限制见 `VALIDATION.md`。受限 Windows 环境的 Next TypeScript 子进程管道有权限限制，本项目使用 Next 支持的 `useTypeScriptCli:false`、线程构建配置。若内存过低，可先独立运行并通过 typecheck，再仅在该次构建设置 `SKIP_BUILD_TYPECHECK=true`；默认 build 仍执行 `tsc --noEmit` 并保留 Next 类型校验。不能用这个开关掩盖实际类型错误。

## 部署

推荐普通 Node 服务器或 Docker，PostgreSQL 17/托管 PostgreSQL，HTTPS 反向代理。不要把这套 Next.js + Prisma PostgreSQL 后端当成静态站点部署。

**Docker Compose**：`.env` 加上 URL 安全的随机 `POSTGRES_PASSWORD` 和至少 32 字符的独立随机 `DATA_ENCRYPTION_KEY`，设置 `DEMO_MODE=false`、`APP_ORIGIN=http://localhost:3000` 或真实 HTTPS origin，以及可选 OpenAI 密钥；运行：

```bash
docker compose up --build -d
docker compose logs migrate web
```

数据库不暴露主机端口，先健康检查→迁移/种子→启动网页。默认网页仅监听本机 3000 端口。数据库卷持久化；迁移服务非零退出时网页不会启动。使用数据库级备份工具备份 `pgdata` 所对应数据库，并验证恢复。

**已有 Node/托管平台**：设环境变量→`pnpm install --frozen-lockfile`→`pnpm db:generate`→`pnpm db:migrate`→`pnpm db:seed`→`pnpm build`→`pnpm start`。Serverless 必须连接外部 PostgreSQL 并设置合适连接池，不使用演示文件。容器采用 Next standalone 输出，非 root 运行。

**Render 公网试点**：仓库根目录的 `render.yaml` 定义一个 Docker 网页服务，部署时在 Render 控制台安全填写 `DATABASE_URL`。可以连接 Neon PostgreSQL 或付费 Render PostgreSQL；请使用带 TLS 的直连地址，勿把连接串写进 Git。容器启动时先执行 Prisma 迁移与幂等种子，再运行 Next.js；`/api/health` 只有在数据库连通时才返回成功。Render 的 `RENDER_EXTERNAL_URL` 可自动用于默认站点的写请求来源校验；绑定自定义域名后，另设 `APP_ORIGIN=https://你的域名`。没有 OpenAI 密钥时继续明确显示规则演示评分。

**Vercel + Neon 免费试点**：从 GitHub 导入本仓库，使用 Next.js 框架，根目录保持仓库根目录。将 Neon 直连 PostgreSQL 地址仅保存为 Vercel 的私密 `DATABASE_URL` 环境变量，另设独立随机的 `DATA_ENCRYPTION_KEY`（至少 32 字符）和 `DEMO_MODE=false`；不设置 `OPENAI_API_KEY` 时仍会明确显示规则演示评分。`vercel.json` 在每次构建前运行 Prisma 迁移和幂等种子，然后执行类型检查与生产构建。生产域名变更后，请在 Vercel 环境变量中设置 `APP_ORIGIN=https://实际访问域名` 并重新部署；预览部署可先依请求 Host 校验。Vercel 函数为按需运行，首次访问可能需要冷启动；数据库始终由 Neon 保存。不要把连接串写进 GitHub。

Render 免费网页服务会在空闲后休眠；**Render 免费 PostgreSQL 会在 30 天后失效，不能作为长期学生档案库**。因此 `render.yaml` 不自动创建数据库，也不授权任何付费资源。要长期保留记录，可接 Neon 等托管 PostgreSQL 并定期异地备份，或在确认费用后使用 Render 付费数据库的时间点恢复；无论哪一种，都不能把恢复窗口当作永久备份。部署前还须核对七条原题的公开转载授权。

备份管理员可在安装了相应版本 PostgreSQL 客户端的受控电脑上，将数据库连接串放入当前进程的 `DATABASE_URL`，运行 `scripts/backup-postgres.ps1 -OutputDirectory <加密存储目录>`。脚本生成自定义格式归档并用 `pg_restore --list` 校验可读性，不把数据库密码作为命令行参数，也不会自动删除旧档。备份文件含学生邮箱和答题记录，应存放在加密、受限且与生产数据库分离的位置；定期在独立测试库演练恢复。仓库默认忽略 `backups/`，不要把归档提交到 GitHub。

公网部署须以线上健康检查和账号流程的实际验证结果为准；未配置 OpenAI 密钥时是规则演示评分，真题授权状态仍须逐条核对。接入模型密钥后还需用教师审核样本检验真实语义评分表现。
